# MVP: проверка перед выпуском

- [ ] `pnpm verify` завершился без ошибок; job `editor_e2e` в MR зелёный.
- [ ] Эталонный screenshot изменился только ожидаемым образом; просмотрены diff и причины изменения.
- [ ] В установленном Safari открыть одну презентацию: фон и пять пунктов списка видны, абзацы не накладываются.
- [ ] Изменить один пункт, передвинуть shape и вставить PNG. Дождаться «Все изменения сохранены», перезагрузить страницу.
- [ ] Скачать PPTX и открыть в PowerPoint/Keynote: текст, положение, изображение, фон и порядок слайдов корректны.
- [ ] Если релиз затрагивает AI: один раз проверить реальную генерацию на разрешённой модели и лимитах; E2E её не вызывает.

Если проверка падает, сохранить trace и вернуться к конкретному шагу по [инструкции отладки](editor-verification.md). Не обновлять screenshot автоматически ради зелёного теста.
