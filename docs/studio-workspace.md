# Личное пространство

`GenerationStudio` координирует данные и создание, `StudioLibrary` содержит список и его
локальные поиск/фильтры/сортировку, `StudioTemplates` — галерею доступных шаблонов.

`/studio/` открывает недавние презентации, а не форму генерации. Боковая навигация на
десктопе становится горизонтальной на телефоне. Разделы отражены в URL:

- `/studio/` — последние 20 проектов, поиск по загруженным темам, статус и сортировка;
- `/studio/?view=create` — прежнее создание через AI, PDF/DOCX/TXT или ответ LLM;
- `/studio/?view=templates` — пять доступных шаблонов с настоящим оформлением.

Переходы между разделами не размонтируют форму: введённый контекст сохраняется в памяти.
Это не новое постоянное хранение формы — обновление страницы сбросит несохранённую тему.
Восстановление обработки документа по job ID продолжает использовать прежний механизм.

`PresentationCover` запрашивает существующий `/editor` только для видимых готовых проектов
и черновиков. Первую сохранённую страницу рисует тот же `SlideSurface`, что в редакторе.
При ошибке обложки проект всё равно можно открыть. Пока содержимое не готово, явно
показывается предпросмотр шаблона, а не выдуманная обложка. `preview_url` каталога теперь
содержит версионированный URL реального фона первого слайда; дополнительного AI-вызова нет.

Открытие редактора остаётся обычной навигацией документа, чтобы сохранялось предупреждение
браузера о несохранённых изменениях при Back. PPTX, отмена черновика, история версий,
старый чат всей презентации и журналы OpenAI сохранены. Последние три находятся в раскрываемых
«Версии, AI и детали» и не перегружают сетку. Логика публикации и авторизации не менялась.

Папки, командные пространства, произвольный импорт PPTX и глобальный серверный поиск не добавлялись.
Это согласованный Pitch-подобный кабинет в дизайне GoDeck, не пиксельная копия. После включения
полного доступа просмотрена видимая часть приватного кабинета Pitch через снимок окна;
чужие ассеты и персональное содержимое не используются в приложении.

Проверки: `pnpm verify`, отдельные сценарии `pnpm test:e2e e2e/studio.spec.ts` в Chromium/WebKit.
Они проверяют реальные обложки, поиск/фильтр/сортировку, переходы с контекстом, выбор шаблона,
историю, сворачивание чата, ошибку обложки, повтор загрузки, пустое состояние и мобильную ширину.
